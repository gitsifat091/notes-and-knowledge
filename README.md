# Notes & Knowledge

A local-first Flutter notes and knowledge management app.

## Planned stack
- Flutter and Dart
- Provider for state management
- Hive for local persistence
- Custom Neumorphism design system with light and dark themes

## Planned capabilities
- Nested folders and subfolders
- Rich-text notes
- Search, tags, favorites, and recent notes
- Password-protected notes and folders
- Local-first storage with an architecture ready for future sync
